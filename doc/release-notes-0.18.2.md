# Garlicoin Core 0.18.2 - GRLC.eu Maintenance Release

Garlicoin Core 0.18.2 is a maintenance release of the actively maintained GRLC.eu edition of Garlicoin Core.

This release continues the modernization and cleanup of the Garlicoin 0.18.x codebase while preserving compatibility with the existing Garlicoin network, blockchain, wallets, addresses and user datadirs.

## Highlights

- improved compatibility with current Linux toolchains, including Ubuntu 22.04 and Ubuntu 24.04
- maintained deterministic builds for Linux, Windows and macOS
- Python 3.12+ compatible P2P functional test framework
- legacy BIP70 Payment Protocol implementation removed
- normal `garlicoin:` payment URIs remain supported
- additional build-system and dependency maintenance
- improved cross-platform CI and release validation
- Garlicoin branding and runtime message cleanup
- GRLC.eu maintained build identification

No consensus rules, proof-of-work parameters, address formats, wallet formats or network identity have been intentionally changed.

This release remains compatible with existing Garlicoin Core datadirs and wallets.
